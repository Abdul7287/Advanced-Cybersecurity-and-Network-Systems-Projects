### Project 05 – Network Scanning and Discovery

This project uses **Nmap** and its GUI tool **Zenmap** to perform comprehensive network scans on an **Ubuntu target system**.  
It compares normal service connections with active scanning behavior, identifying open ports and running services.  
Captured traffic in **Wireshark** helps distinguish legitimate communication from aggressive scanning activity, emphasizing how network mapping tools can be used for both security auditing and intrusion detection.
