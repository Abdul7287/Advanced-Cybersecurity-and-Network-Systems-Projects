### Project 07 – Tor and Tails Anonymous Communication

This project explores **anonymous communication and privacy protection** using the **Tails operating system** and the **Tor network**.  
It demonstrates secure file sharing via **OnionShare**, traffic capture with **tcpdump**, and verification of Tor relay nodes.  
Through **Wireshark** analysis, the project highlights how layered encryption and routing through multiple Tor nodes provide **anonymity, confidentiality, and resistance to surveillance**.
