### Project 04 – Firewall and MAC Filtering

This project focuses on **network traffic control and filtering** using **IPTables** in Linux.  
It demonstrates how to block and redirect ports, filter packets by **MAC address**, and analyze the effectiveness of these rules using **Wireshark**.  
Additionally, it explores **MAC spoofing** with Macchanger, showing the limitations of MAC based filtering in real-world network defense.
