# Advanced Cybersecurity and Network Systems

My repo presents a collection of advanced, hands-on projects in **cybersecurity and network systems**, demonstrating both **offensive** and **defensive** security practices.  
Each project explores a different domain of applied security, from encryption and steganography to firewall configuration, honeypots, and anonymous networking.

---

## 🔐 Overview

These projects were conducted in virtualized environments using **Kali Linux**, **Ubuntu**, and **Tails OS**, integrating multiple open-source security tools.  
The focus is on understanding real-world system vulnerabilities, secure communication, and data protection through simulation, testing, and analysis.

---

## 🧩 Project Topics

| # | Project Title | Focus Area | Tools Used |
|---|----------------|-------------|-------------|
| **1** | Network Traffic Analysis | Capturing and analyzing unencrypted data in transit | Kali Linux, Wireshark, Netcat |
| **2** | File Encryption and Steganography | Symmetric/asymmetric encryption, digital signatures, hidden data | GPG (GNU Privacy Guard), Steghide, md5sum |
| **3** | SSH Brute-Force Attack Simulation | Offensive security & password cracking via Hydra | Hydra, Wireshark, SSH |
| **4** | Firewall and MAC Filtering | Configuring IPTables for port blocking, redirection, spoofing | IPTables, Macchanger, SSH |
| **5** | Network Scanning and Discovery | Network mapping and service identification | Nmap, Zenmap, Netcat, Python Server |
| **6** | Honeypot Implementation | Creating fake network services and analyzing attack logs | Netcat, Python, Nmap, Wireshark |
| **7** | Tor & Tails Anonymous Communication | Secure browsing and data sharing through the Tor network | Tails OS, OnionShare, GnuPG, tcpdump, Wireshark |

## ⚙️ Skills and Tools Demonstrated

- 🔑 **Encryption & Authentication:** GPG, RSA keys, symmetric/asymmetric encryption  
- 🕵️ **Offensive Testing:** Hydra brute-force attacks, Nmap scanning, Zenmap mapping  
- 🧱 **Network Defense:** IPTables firewalls, port redirection, MAC filtering  
- 🎭 **Data Hiding & Integrity:** Steghide, md5sum hashing, digital signatures  
- 🧲 **Traffic Analysis:** Wireshark, tcpdump, Netcat, protocol dissection  
- 🧪 **Deception & Detection:** Honeypot setup for service logging and attack tracing  
- 🧩 **Anonymity & Privacy:** Tor routing, Tails OS, OnionShare secure file sharing

## 📊 Technical Environment

- **Operating Systems:** Kali Linux, Ubuntu, Debian, and Tails OS  
- **Virtualization:** Oracle VirtualBox
