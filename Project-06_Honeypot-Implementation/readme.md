### Project 06 – Honeypot Implementation

This project demonstrates how to create and deploy a **basic honeypot** using **Netcat** and **Python** to simulate real network services such as **FTP**, **SMTP**, **Telnet**, and **SSH**.  
By capturing and logging incoming connection attempts, it provides insight into **attacker behavior**, scanning patterns, and intrusion techniques.  
Traffic analysis in **Wireshark** supports detection and understanding of reconnaissance activities on vulnerable systems.
